This project uses Neon/Postgres through Prisma for application data.

When changing database-backed behavior, update `prisma/schema.prisma` first, keep Prisma access behind the existing lazy database helpers, and run `bun run prisma:generate` after schema edits.

## Local mask service

Three of the editor's AI tools — **Select Subject** (BiRefNet), **SAM 2 click-to-select**, and **Depth Anything V2** — depend on a local Python service at `services/segment/`. Additional capabilities served by the same service: YOLO multi-instance detection (`/segment/instances`), CLIPSeg text grounding (`/ground/text`), LaMa inpainting (`/inpaint`), and AI auto-crop (`/crop/auto`).

Required environment variable in `.env.local`:

```env
MASK_SERVICE_URL=http://127.0.0.1:8001
```

Without it, SAM 2, Depth, YOLO, CLIPSeg, and LaMa tools return **501**. Select Subject falls back to HuggingFace APIs.

To start the service in dev: `bun run mask:dev` (or `cd services/segment && python main.py`).

## Agent command registry

All editor capabilities are registered as named commands via `registerDomain(domain, defs)` in `src/lib/agent/command-registry.js`. Registered domains:

- `mask.*` — subject selection, SAM 2, YOLO detection, NL masking, boundary expand
- `crop.*` — AI auto-crop (4 strategies), manual box apply
- `collage.*` — createTemplate, fromDescription, autoTemplate, generateBackground, setBackground, listLayouts, listStyles

Access at runtime: `window.__pixxel.agent.listCommands()` / `runCommand(id, args)`.

The agent chat (`imagekit-agent.jsx`) routes prompts:
- **Collage intent** (`COLLAGE_INTENT_RE`) → `collage.fromDescription`
- **Edit intent** → Gemini grade loop
- **Mask intent** → `mask.fromDescription`

## Collage engine

- Pure geometry in `src/lib/collage-layout.js` (no React) — shared by the tool UI and agent commands
- Style presets, backdrops, clip-path/shadow builders in `src/lib/collage-styles.js`
- Agent commands in `src/lib/agent/collage-commands.js`
- Cell framing uses Fabric `absolutePositioned` clipPaths (Rect rounded / Ellipse circle) — serializes natively with canvas state
- AI backgrounds generated by sampling dominant photo colors → `buildAiBackgroundPrompt` → POST `/api/ai/background` with `raw:true`

## Critical invariants

- **Never `requestRenderAll` mid-stroke** in mask/erase brush tools — triggers full scene redraw + `after:render` DOM sync per frame causing cursor lag. Paint to `contextTop` only.
- **Never commit `blob:` URLs** into Fabric images — upload to ImageKit (data:-URL fallback). Blob URLs are page-scoped and break undo/redo and persistence.
- **Never match Fabric objects by identity** after undo/redo — `loadFromJSON` recreates all objects. Match by `src`/props.
- **Never read localStorage in `useState` initializers** — SSR prerenders cause hydration mismatches. Sync in `useEffect` instead.
- **`visibilitychange→hidden` must use a normal flush** (advances `baseRevision`), not `beaconUnload` — the beacon path caused spurious "edited on another device" conflicts on a single window.
